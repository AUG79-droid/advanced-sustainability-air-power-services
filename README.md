# Advanced Sustainability in Air Power Services

A complete, self-paced web training application for Air Power Services employees.

The course includes six in-depth modules, saved learning progress, interactive
laboratories, module knowledge checks, the Orion capstone, a final assessment,
downloadable learning resources, and a printable certificate.

## Run locally

Requires Node.js 22.13 or later.

```bash
npm ci
npm run dev
```

Open the local URL shown in the terminal.

## Validate and create a static build

```bash
npm run lint
npm test
```

The production-ready static site is generated in `out/`.

## Course scope

The learning experience treats safety, airworthiness, security, and mission
requirements as non-negotiable constraints. It distinguishes civil aviation
frameworks from State and military aviation contexts and includes controls
against unsupported environmental claims.
